# Changelog

## REV1

- Initial standalone XT Serial Matrix Co-Processor project.
- 8088/8086 DOS ASM side with COM settings, baud selection, and green VGA text dashboard.
- Windows C# serial host with fixed no-scroll dashboard.
- Deterministic seed-stream matrix generation for large 4096 x 4096 jobs.
- Fixed-width serial responses for clean 8088 screen formatting.
- Build scripts for TASM/TLINK, .NET Framework/MSBuild, and modern dotnet SDK.
