XT / 8088 SERIAL MATRIX CO-PROCESSOR REV1
==========================================

This is a new project based on the working serial prime co-processor style.

WHAT IT DOES
------------

8088 / DOS side:
  - Shows the same green-on-black VGA style dashboard.
  - Lets you select COM port, baud rate, delay, and matrix size.
  - Generates new 16-bit random seeds on the 8088 for every data set.
  - Sends a compact request to the PC over RS-232.
  - Shows TX/RX bytes-per-second and the returned matrix results.
  - Runs forever until Q or ESC.

PC / C# side:
  - Opens the selected COM port.
  - Uses a fixed no-scroll console dashboard.
  - Shows RECEIVING, PROCESSING, TRANSMITTING, and WAITING states.
  - Expands the 8088-generated seeds into deterministic random matrices.
  - Calculates matrix multiplication fingerprints and sample cells.
  - Sends a compact fixed-width result line back to the 8088.

IMPORTANT NOTE ABOUT 4096 X 4096
--------------------------------

A real 4096 x 4096 matrix has 16,777,216 numbers.
Two matrices have 33,554,432 numbers.

Sending every single number across a 9600 baud serial link would take many
hours before the PC could even start calculating. So this REV1 uses a practical
seed-stream method:

  1. The 8088 generates the random data-set seeds.
  2. The 8088 sends those seeds and the matrix size to the PC.
  3. The PC expands those seeds into the exact random matrices.
  4. The PC performs real A*B matrix multiplication fingerprint math.
  5. The PC returns compact results for the 8088 to display.

The PC calculates:
  - SUM MOD:  checksum/fingerprint of all A*B result elements.
  - DIAG MOD: checksum/fingerprint of the A*B diagonal.
  - C00:      sample result cell C[0,0].
  - CMID:     sample result cell C[N/2,N/2].
  - CLAST:    sample result cell C[N-1,N-1].

The values are displayed modulo 10,000,000,000 so they always fit nicely in
10 digits on the 8088 screen.

PROTOCOL
--------

8088 sends:

  MAT,00001,04096,12345,54321*XX

Fields:

  MAT       matrix request
  00001     request sequence
  04096     matrix size N
  12345     A matrix seed generated by the 8088
  54321     B matrix seed generated by the 8088
  XX        XOR checksum of all characters before the '*'

PC returns:

  RSP,00001,04096,12345,54321,1234567890,1234567890,1234567890,1234567890,1234567890,00123*XX

Fields:

  RSP       response
  seq       matching request sequence
  N         matrix size
  seedA     A seed
  seedB     B seed
  sumMod    all-result checksum/fingerprint
  diagMod   diagonal checksum/fingerprint
  c00       sample C[0,0]
  cmid      sample C[N/2,N/2]
  clast     sample C[N-1,N-1]
  ms        PC processing time in milliseconds
  XX        XOR checksum

BUILD 8088 / DOS SIDE
---------------------

Use the 8.3 DOS source file:

  XTMAT1.ASM

Build with TASM/TLINK:

  BUILD_XT.BAT

or manually:

  TASM XTMAT1
  TLINK XTMAT1
  XTMAT1

A long-name copy is also included for GitHub/readability:

  XT8088MAT_REV1.ASM

BUILD PC / C# SIDE
------------------

Go into:

  SerialMatrixCoproc

Best first build:

  build_framework.bat

Run examples:

  run_COM3_9600.bat
  run_COM1_9600.bat
  run_interactive.bat

Manual run:

  SerialMatrixCoproc.exe COM3 9600

PC dashboard keys:

  Q     quit
  ESC   quit
  C     clear PC-side counters

8088 runtime keys:

  S     settings menu / reinitialize serial
  R     reset seeds
  Q     quit
  ESC   quit
